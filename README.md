# Football Analytics Platform

## Overview

This Football Analytics Platform is a portfolio project that demonstrates modern backend software development using .NET.

The project will start as a single ASP.NET Core Web API before evolving into an event-driven microservices platform.

The aim is to gain practical experience designing, implementing, testing and deploying scalable backend systems while documenting the engineering decisions made along the way.

## Architecture Roadmap

The project is intentionally built in stages.

1. Project setup
2. Fixtures API
3. API quality improvements
4. PostgreSQL
5. Automated testing
6. Docker Compose
7. Performance testing
8. Kafka
9. Analytics microservice
10. Redis
11. Identity service
12. API Gateway
13. Observability
14. Kubernetes
15. Azure infrastructure
16. CI/CD

Each stage introduces one major concept before moving on to the next.

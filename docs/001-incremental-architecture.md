# Project Goals

## Purpose

The goal of this project is to build a production-style football analytics platform while learning modern backend engineering practices.

Rather than building a complete system immediately, the platform will evolve incrementally by introducing one technology or architectural concept at a time.

This approach allows each decision to be understood, tested and documented before increasing the overall complexity of the system.

## Objectives

- Build a well-structured ASP.NET Core API
- Apply Clean Architecture principles
- Learn PostgreSQL and Entity Framework Core
- Design event-driven microservices using Kafka
- Implement caching with Redis
- Secure APIs using JWT authentication
- Route requests through an API Gateway
- Add distributed tracing and structured logging
- Deploy to Kubernetes
- Provision Azure infrastructure using Terraform
- Build automated CI/CD pipelines

## Success Criteria

The project will be considered successful if it demonstrates production-ready engineering practices while remaining understandable, maintainable and well documented.

Every major architectural decision should be supported by an Architecture Decision Record (ADR) and every milestone should be accompanied by documentation explaining what was built and why.
